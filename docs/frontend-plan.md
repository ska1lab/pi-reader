# 前端布局与页面实施计划

采用方案二：Nuxt Layout 承载常驻导航，会话页面通过独立路由展示。先完善页面，再接入业务功能，让后续开发可以直接在浏览器中检查和验收。

本文规定前端页面的结构、区块、实施顺序和完成条件。项目整体范围见[项目计划](plan.md)，已有约束见[决策记录](decisions.md)。以下切片均为待实施计划。

## 实施边界

- 使用项目现有的 Nuxt、Nuxt UI 和 Tailwind CSS，复用已有消息、输入和模型选择组件。
- 页面由集中维护的示例数据驱动，预留有类型的数据入口、组件事件和业务操作回调。
- 实现折叠、路由跳转、弹窗、菜单、输入、选项切换等界面交互。创建、搜索、重命名、分叉、归档、发送、停止、上传和保存配置等业务动作保留调用入口。
- 示例会话 ID 只用于页面预览。业务动作的点击不调用真实接口，也不自动生成任务成功、消息已发送或配置已保存等结果；这些展示状态通过示例数据切换检查。
- 本阶段的代码改动集中在前端；真实 Pi 会话、服务端接口和持久化能力留在后续功能切片中接入。
- 已移除的界面包括整个右侧工具区、插件和自动化任务入口、连接状态入口、会话标题旁的操作与面包屑、会话视图切换、工作区视图选项，以及输入区的权限模式和计划模式。

## 垂直切片与完成条件

按下表顺序实施。每片交付一条可在浏览器中检查的页面体验，并满足文末的通用验收要求。

| 切片 | 覆盖区块 | 页面交付内容 | 完成条件 |
| --- | --- | --- | --- |
| 1. 进入工作台与会话页面 | A1、B1、整体框架 | 接入 Layout；建立首页和会话路由；完成左右两栏、品牌、折叠控制、标题；用现有消息和输入组件形成最小页面。 | 两个示例会话 URL 展示各自的标题与内容；直接访问和刷新正常；未知 ID 有明确空态；折叠左栏后主区域正确扩展。 |
| 2. 浏览工作区并切换会话 | A2、A3 | 完成新建入口、搜索输入框、添加工作区入口、工作区折叠列表、会话行和操作菜单；提供选中、运行、归档等行状态。 | 点击示例会话完成路由切换，选中项与 URL 一致；新建入口进入首页；搜索和管理动作触发预留事件；长列表独立滚动，展开和菜单操作不造成水平位移。 |
| 3. 使用新会话页面 | 新会话状态、B5 | 完成欢迎语、工作区选择、Agent 模式选择位置和居中输入框；提供未选工作区、已选、输入不可用等状态。 | 不显示会话标题；选择器和占位文字随示例状态变化；宽窄屏均可使用；与已有会话页面复用输入组件。 |
| 4. 阅读完整会话内容 | B1、B3 | 展示用户消息、AI 回复、Markdown、代码、图片、附件、交付文件卡片，以及可折叠的思考和工具过程；建立正文滚动与输入区贴底关系。 | 长对话、长代码、宽表格和长工具结果均可阅读；展开过程不会遮住底部操作；标题始终只显示会话名称；文件卡片动作预留事件入口。 |
| 5. 编辑消息与使用输入控件 | B5 | 完成多行输入、附件展示、引用与命令补全菜单、模型与推理强度选择、发送和停止按钮；覆盖空输入、输入中、发送中、执行中和失败状态。 | 菜单和选择器可开关；草稿和示例附件可在本地编辑；模型选项可选择；按钮显隐与禁用状态正确；业务动作触发回调；首页与会话页使用相同控件。 |
| 6. 查看统计信息 | B6 | 完成用量摘要、上下文占用率和详情浮层；提供正常、接近容量、未知及无数据状态。 | 展示数值来自示例数据；浮层可打开、关闭且保持在视口内；长数字不破坏窄屏布局；未知值有明确展示，无数据时按规则隐藏。 |
| 7. 打开设置页面 | A4、设置弹窗 | 完成设置入口、弹窗、分类导航、内容区域和关闭操作；分类与内容采用可替换的示例数据。 | 设置可打开、关闭和切换分类；长内容在内容区域滚动；关闭后焦点回到入口；窄屏使用全屏布局；保存动作仅保留调用入口。 |

## 结构示意

页面采用左侧导航栏和中间会话区。中间区域占满左栏之外的剩余宽度。沿用讨论中的区块编号，共保留 8 个区块。

```text
┌────────────────────┬────────────────────────────────────┐
│ A1 品牌与折叠控制  │ B1 会话标题                        │
├────────────────────┼────────────────────────────────────┤
│ A2 新建会话        │                                    │
├────────────────────┤ B3 会话内容区                      │
│ A3 工作区与会话    │                                    │
│                    │ 用户消息、AI 回复                  │
│ 搜索 / 添加工作区  │ 思考过程、工具调用                 │
│                    │ 图片、附件、交付文件卡片           │
│ ▾ 工作区 A         │                                    │
│   会话 1           │                                    │
│   会话 2           │                                    │
│ ▾ 工作区 B         │                                    │
│   会话 3           ├────────────────────────────────────┤
│                    │ B5 消息输入区                      │
│                    │ 输入文字、附件、引用               │
│                    │ +                   模型  发送/停止 │
├────────────────────┼────────────────────────────────────┤
│ A4 设置入口        │ B6 统计信息                        │
└────────────────────┴────────────────────────────────────┘
```

## 区块职责

| 编号 | 区块 | 内容与布局 |
| --- | --- | --- |
| A1 | 品牌与折叠控制 | 品牌标识、名称和展开或收起左栏的控件，位于左栏顶部。 |
| A2 | 新建会话 | 单一的新建会话入口，位于品牌下方，导航至新会话页面。 |
| A3 | 工作区与会话 | 搜索、添加工作区、工作区展开或收起、会话列表，以及置顶、重命名、分叉、归档等操作入口；列表独立滚动。 |
| A4 | 设置入口 | 固定在左栏底部，点击打开设置弹窗。 |
| B1 | 会话标题 | 仅显示当前会话名称，位于会话区顶部。 |
| B3 | 会话内容区 | 展示消息、思考、工具过程、图片、附件和交付文件卡片，是会话的主要阅读区域。 |
| B5 | 消息输入区 | 多行输入、附件、`@` 引用、`/` 命令与技能、模型与推理强度、发送和停止；已有会话中贴底显示。 |
| B6 | 统计信息 | 位于输入框下方，展示会话用量、上下文占用率及详情入口；可用性由展示数据决定。 |

## 路由与页面状态

| 路由或状态 | 页面表现 |
| --- | --- |
| `/`：新会话 | 中央展示欢迎语、工作区选择、Agent 模式选择位置和输入框，隐藏 B1。新建会话入口只导航到此页。 |
| `/sessions/:id`：已有会话 | 展示 B1、B3 和底部输入区域；B6 按示例数据出现。 |
| 加载中、空会话或读取失败 | 保留页面框架，在对应内容区域呈现状态，提供重试操作入口。 |
| 未知示例会话 ID | 显示未找到会话及返回入口，不回退显示其他会话。 |
| 设置打开 | 在当前页面上覆盖设置弹窗，保留原路由、草稿和正文位置。 |

当前会话 ID 以 URL 为准，侧栏选中项和展示数据均从该 ID 派生。工作区展开状态、草稿、菜单和弹窗由前端管理；草稿按示例会话区分，首页使用独立草稿。

## 示例数据与预留接口

数据流：路由会话 ID → `useWorkbench` 读取对应示例数据 → 区块组件通过 props 展示；用户操作 → 组件事件 → 预留操作回调。后续接入时替换数据来源和回调实现。

| 接口类别 | 预留内容 |
| --- | --- |
| 展示数据 | 工作区、会话目录、当前会话、结构化消息、模型选项、推理强度和统计信息。 |
| 导航与布局 | 选择会话、进入首页、折叠左栏、展开工作区、打开或关闭设置。 |
| 工作区与会话操作 | 搜索、添加工作区、新建、置顶、重命名、分叉、归档和恢复。 |
| 输入操作 | 发送、停止、上传、获取引用或命令候选、切换模型和推理强度。 |
| 文件与设置操作 | 打开或下载文件，以及保存设置。 |

展示类型先表达前端需要的状态，不视为最终 HTTP 协议或 Pi 原始事件。业务回调包含目标会话及操作所需信息；各区块通过明确的 props 和事件协作。

示例数据集中提供默认、长内容、加载、空白、失败和执行中等场景，并提供简单的前端切换方式。预览页面标明数据为示例；预留回调可供开发时检查触发参数。展示业务成功状态时使用显式场景，避免由空实现返回伪成功。

## 每片通用验收

- 在浏览器实际操作本片新增入口，核对路由、选中项、菜单、弹窗和回调参数；记录实际通过项与未完成项。
- 检查本片涉及的默认、空白、加载、失败和执行状态；重新进入或刷新示例页面后仍可复现。
- 至少检查 1440px、768px 和 375px 宽度，以及长内容场景。正文、输入区和浮层保持可用，代码和表格使用局部横向滚动。
- 检查 Tab 焦点顺序、图标按钮名称、菜单和弹窗的 Escape 关闭，以及关闭后的焦点恢复。
- 检查控制台错误和意外网络请求，确认预览操作未调用真实业务接口。
- 运行项目已有的类型检查；布局或行为在本片内验收，后续切片继续保持已完成页面可用。

## 后续接入时确认

- Agent 模式的实际选项、设置分类与具体配置项由后续需求确定，当前只用示例数据检查呈现。
- 产物和自定义终端组件的实际数据协议按所用 Pi 扩展逐项确认。
- 功能开发逐片接入真实数据、请求和执行状态，复用本计划完成的页面作为浏览器验收入口。
