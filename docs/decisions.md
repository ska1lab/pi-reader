# decisions.md

## 2026-10-25 跳过"设置默认模型"功能
- 决定：session.setModel() 只切换当前会话，不写入 Pi 用户配置
- 原因：练习阶段不需要，避免操作用户全局配置
- 放弃：persist 参数和保存按钮；以后做多会话时再评估

## 2026-10-27 采用 Nuxt Layout 与会话路由

- 决定：采用方案二，通过 Nuxt Layout 和独立会话路由组织前端页面。
- 原因：采纳建议，理由：希望后续切换会话更方便。
- 放弃：方案一：单页容器与区块组件。
- 重新评估：暂无。

## 2026-10-27 先完善前端页面，再开发功能

- 决定：先开发前端布局和页面，预留功能接口，后续接入业务功能。
- 原因：功能开发完成后，可以直接在页面中进行测试。
- 放弃：从业务功能开发开始。
- 重新评估：暂无。
